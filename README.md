# Kalkulator Luas Bangun Datar

Aplikasi sederhana untuk menghitung luas beberapa bangun datar. Project ini dibuat sebagai latihan belajar Vue 3, TypeScript, dan pengembangan aplikasi web.

## Fitur

- Menghitung luas persegi panjang
- Menghitung luas persegi
- Menghitung luas segitiga
- Menghitung luas lingkaran
- Menghitung luas jajar genjang
- Menghitung luas trapesium
- Menghitung luas belah ketupat atau layang-layang

Input angka dilakukan melalui dialog prompt browser, lalu hasilnya ditampilkan pada halaman.

## Teknologi

- Vue 3
- TypeScript
- Vite

## Menjalankan Project

Pastikan Node.js dan npm sudah terpasang, lalu jalankan:

```sh
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan Vite di terminal.

## Build dan Pemeriksaan Tipe

```sh
npm run type-check
npm run build
```
